# W12SE-ENHANCED

(Goal: To Make A Version Of The Windows SE Project Series That Is More Modern, Wider And More User Friendly)

## What Is The Windows SE Series?

The Windows SE Series Is A Collection Of Projects That Aim To Recreate A Windows Experience With More Animations And Features In Electron And HTML.

## What Is Windows 12 SE Enhanced?

The Original Windows 12 SE Project Went Bad And Unusable, Its Still Available On itch.io But I Decided I Want To Revive This Project And Not Make It Small Like The Original Projects In The Series Im Making Wider And More Functional Plus Being Fun To Use.

## Why Can't I Find Releases?

I Haven't Made Any Releases Yet Because The Project Is Still In The Development Stage.

(This Project Is Only Made For Fun)

## Why Is This Project Not On itch.io?

I Put This Project On Github And Not itch.io Because For Early Access Releases It Won't Be Easy To Update The itch.io Project Will Come Out When The Game Is Released. You Can Still Find The Original Cancelled Project On itch.io (https://tsubasagames.itch.io/windows12se)
